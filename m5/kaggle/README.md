# Running the M5 forecast on Kaggle

`m5-forecast.ipynb` is a self-contained notebook for the
[M5 Forecasting - Accuracy](https://www.kaggle.com/competitions/m5-forecasting-accuracy)
competition. It contains the repository's pipeline modules, trains every model from scratch on
Kaggle's data and writes `submission.csv`. It is generated by `tools/build_kaggle_notebook.py`,
so it always matches the code in `m5/src/`.

## Steps

1. Open the competition page, accept the rules if you have not, and go to **Code → New Notebook**.
2. **File → Import Notebook** and upload `m5-forecast.ipynb`.
3. In the right-hand panel: **Add Input → Competitions → M5 Forecasting - Accuracy**. The
   notebook finds the data wherever Kaggle mounts it.
4. Settings: **Accelerator: None** (CPU; LightGBM here does not use a GPU). Internet can stay off.
5. Optional quick check: set `QUICK = True` in the settings cell and run all cells. The pipeline
   runs end to end with 5 trees per model and writes a (poor) submission.
6. For the real run: `QUICK = False`, then **Save Version → Save & Run All (Commit)**. Kaggle
   runs it in the background, up to 12 hours.
   - `RUN_WINNER = True` (default): this pipeline + the winner's recipe, about 7–8 hours.
   - `RUN_WINNER = False`: this pipeline only, about 1.5–2 hours.
7. When the version finishes, open it, go to **Output**, and click **Submit** next to
   `submission.csv`.

## What to expect

- Kaggle scores late submissions but does not rank them.
- This pipeline alone reproduces the project's reported private score of **0.5866**, give or
  take small differences in LightGBM threading.
- With `RUN_WINNER = True` the submission is the 50/50 combination. It was chosen on three windows
  that played no part in any choice (mean WRMSSE 0.599 against 0.616 and 0.626 for the two
  halves), before its private-window score was known. The private window itself was already
  public when this notebook was written, so its score is a check, not a result.

## Rebuilding the notebook

```bash
python3 tools/build_kaggle_notebook.py
```
