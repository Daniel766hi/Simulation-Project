# Congratulations page for Karen

A small web page celebrating Karen finishing her internship (kerja praktik) defense: a "Laporan KP"
folder to tap open, confetti, a polaroid photo wall, "Karen Wrapped" story slides, "Semua Aku
Dirayakan" on Spotify, flip cards, a letter from Daniel, a KP report to stamp "SELESAI", and a
scratch card. Built from the `sherryn/` gift page, without its birthday theme.

- **Text and photos:** everything is in `config.js`; photos live in `photos/`.
- **Music:** `music/loop.mp3` is the background loop (rendered by `tools/make_gift_music.py`).
  Set `spotifyTrack` in `config.js` to add a song through Spotify's player.
- **Preview:** open `index.html` in a browser, or use the deployed site at `/karen/`.
